# Royal Wedding Invitation — Chi. Rajesh Mani Kumar & Chi. La. Sow. Nidharshini

An exquisite, royal Indian wedding invitation website featuring an interactive 3D WebGL miniature entrance walk, authentic Telugu and English multilingual support, auspicious countdown timer, romantic background music, venue directions, and photo gallery.

- **Groom:** Chi. Rajesh Mani Kumar (IIT, B.Tech.)

- **Dinner Reception:** 8:00 PM Onwards
- **Venue:** ARM CONVENTION, MG Inner Ring Road, Phase-1, Gorantla, Guntur, Andhra Pradesh

## ✨ Features
- **Royal Wax Seal & Unsealing Gate:** Immersive opening screen that seamlessly unlocks audio playback and parts the velvet palace curtains.
- **3D Miniature Palace Walk:** Interactive Three.js WebGL scene with realistic lighting, floating flower petals, and 3D miniature couple figurines.
- **Bilingual Support:** Seamless switching between English and authentic Telugu script (`తెలుగు` / `English`).
- **Responsive Design:** Optimized for all screen sizes from compact mobile devices (iPhone SE, Galaxy Fold) to tablets, laptops, and ultra-wide desktops.
- **Romantic Background Score:** Preloaded romantic BGM with audio controls.
